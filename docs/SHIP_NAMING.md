# 宇宙船の名前の見直し（2026-10-20）

基準：SFや宇宙開発に詳しくない日本の高校生に伝わること。カタカナの専門用語（ペイロード・ラック・バス・ピーク）や、分野の言い回し（給電許可・負荷区分・熱保護・定格）を、日常の言葉に置き換えました。画面・報告・ヒント・解説・設計資料に共通で使います。

## 部屋・役割

| 旧 | 新 |
|---|---|
| 航法室・航法担当 | 操縦室・操縦担当 |
| 科学ラボ・科学担当 | 実験室・実験担当 |
| 熱管理室・熱制御担当 | 冷却管理室・冷却担当 |
| 機器ベイ | 電子機器室 |
| 熱制御区画 | 冷却装置区画 |

生命維持室・生命維持機械室・電力管理室・電源室・船外はそのままです。

## プロパティ

| 旧 | 新 |
|---|---|
| 冷却ポンプの負荷区分（1=重要負荷、0=一般負荷） | 冷却水ポンプの優先度（1=最優先、0=ふつう） |
| 重要負荷・一般負荷・先着順 | 最優先の機器・ふつうの機器・早い者順 |
| 割り当て容量 | 配れる電力の合計 |
| 増産時の要求電力 | 増産時に申請する電力 |
| 熱保護の作動温度・解除温度 | 過熱防止が働く温度・過熱防止を解く温度 |

| 校正オフセット | 表示のずれの補正 |
| 報告周期・計測周期・計算周期 | 測る間隔・計算する間隔 |
| 制御ゲイン | 温度1 °Cあたりに増やす流量 |
| 温度変化の係数・冷却液の熱交換係数 | 温まりやすさ・冷却水の冷やしやすさ |

内部のID（`pdu`・`pumpEssential` など）は変えていません。旧PoC（抽象）と、過去の作業報告・検討資料の文面も変えていません。
